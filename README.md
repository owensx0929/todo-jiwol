# 백지월의 할 일 목록

Supabase에 할 일을 저장하는 간단한 Todo 웹 앱입니다.
HTML/CSS/JavaScript로 화면을 만들고, GitHub에 올린 코드를 Vercel로 배포했습니다.

**배포 주소:** https://todo-jiwol.vercel.app

## 주요 기능

- **할 일 추가 / 완료 / 삭제**: 체크박스로 완료 표시를 하고, ✕ 버튼으로 삭제합니다. 완료한 항목은 한 번에 지울 수도 있습니다.
- **작성자**: 할 일마다 작성자 이름을 적을 수 있습니다(선택). 추가한 뒤에도 이름이 입력칸에 남아 있어서 연달아 입력하기 편합니다.
- **마감일과 정렬**: 마감일을 정할 수 있고, 마감일이 가까운 순서로 정렬됩니다. 마감일이 없는 할 일은 맨 아래에 보입니다. 오늘 마감과 지난 마감은 색으로 구분됩니다.
- **더블클릭 수정**: 할 일 글자를 더블클릭하면 고칠 수 있습니다. Enter는 저장, Esc는 취소이고, 내용을 다 지우면 원래 내용으로 돌아갑니다. 한글 입력 중 Enter 때문에 두 번 저장되지 않도록 처리했습니다.
- **필터**: 전체 / 진행 중 / 완료로 나눠 볼 수 있습니다.
- **남은 할 일 수**: 화면 위쪽에 남은 할 일, 전체, 완료 개수가 표시됩니다.
- **실시간 검색** (직접 추가한 기능): 검색창에 글자를 입력하면 그 글자가 들어간 할 일만 바로 보입니다. 대소문자를 구분하지 않고, 필터와 함께 작동합니다. 예를 들어 '진행 중'을 고른 상태에서 검색하면 진행 중인 할 일 중에서만 찾습니다.
- **중요 표시**: ★ 버튼으로 중요한 할 일을 표시할 수 있습니다.

## 사용 기술

| 구분 | 기술 |
|---|---|
| 화면 | HTML, CSS, JavaScript |
| 데이터 저장 | Supabase (`todos` 테이블) |
| 코드 관리 | GitHub |
| 배포 | Vercel (main에 push하면 자동 배포) |

## 파일 구성

```
index.html   화면, 스타일, 앱 동작 코드
config.js    Supabase 주소와 publishable key
```

## 로컬에서 실행하기

`index.html`을 바로 열면 `config.js`를 불러오지 못할 수 있어서 간단한 서버로 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다.

## 보안 및 한계

- **secret key는 사용하지 않습니다.** 앱에는 브라우저에 공개되어도 되는 publishable key만 들어 있습니다.
- Supabase `todos` 테이블에는 **RLS(행 수준 보안)가 켜져 있습니다.**
- 다만 **로그인 기능이 없는 공유 목록**입니다. 그래서 사이트에 접근할 수 있는 사람은 누구나 할 일을 읽고, 추가·수정·삭제할 수 있습니다.
- 사람마다 자기 할 일만 보이게 하려면 로그인 기능과 사용자별 RLS 정책을 추가해야 합니다.
